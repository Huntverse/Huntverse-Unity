UI Node Graph · Bake ~ UIManager 처리 과정

에디터 Bake 데이터 런타임
1. 노드 설정 (에디터)
UI Node Graph Editor에서 노드 추가·연결, Button/GameObject/레이어 참조 지정
↓
UINodeGraph (ScriptableObject) 에셋에 nodes, connections 저장
2. Bake 실행
노드가 참조하는 각 GameObject에 UIGraphTarget 부착 · GetOrCreateTargetId로 GUID(TargetId) 부여
↓
연결 기준 위상 정렬 → 실행 Step 리스트(bakedData.executionSteps) 생성 (레이어/오브젝트는 GUID로 저장)
↓
ButtonClickNode/KeyboardInputNode에 대해: 해당 버튼·오브젝트에 UIGraphBakedEvent/UIGraphBakedKeyboardEvent 부착 (graph, startNodeGuid 저장)
3. Bake 결과 (ScriptableObject · GUID)
UINodeGraph 에셋에 bakedData(executionSteps) 직렬화 저장
각 UI GameObject는 UIGraphTarget으로 고유 TargetId(GUID) 보유
버튼/키 오브젝트는 Baked 이벤트 컴포넌트로 “어느 그래프 · 어느 노드부터” 정보 보유
4. UIManager 처리 (런타임)
씬 로드 시 RegisterAllSystemsInScene
↓
targetRegistry.RegisterAllGraphTargetsInScene() → 씬 내 UIGraphTarget 전부 ID로 등록 (ID → GameObject 조회 가능)
↓
eventManager.RegisterAllBakedEventsInScene() → UIGraphBakedEvent는 Button.onClick에, UIGraphBakedKeyboardEvent는 키맵에 등록
↓
버튼/키 입력 시 Baked 이벤트 → UIManager.ExecuteGraphFromNode(graph, startNodeGuid)
↓
UIGraphExecutor: connections 기준 BFS로 실행할 Step 수집 → Step 순서대로 ExecuteStep (targetRegistry.FindGameObjectById 등으로 실행)
씬 언로드 시 해당 씬의 Baked 이벤트만 해제. GameObject 참조는 런타임에 GUID로만 조회하므로 씬 구조 변경에 비교적 안정적.
